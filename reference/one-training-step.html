One training step

A model with one weight, a positive input, and one example.

Compute

prediction = weight × input

loss = (prediction − target)²

Loss is zero only when the prediction equals the target. Nielsen’s cost is this idea averaged over a dataset. Frameworks call it loss.

Decide

Input positive:

  • Prediction below the target → raise the weight.
  • Prediction above the target → lower the weight.
  • Prediction equal to the target → leave the weight.

The rule this is a picture of

new value = old value − learning rate × slope of the loss

Nielsen writes v → v − η∇C. The learning rate η is a small positive number. The minus sign walks downhill. Lesson 0001 steps by 1 so the direction is visible; a real update takes a smaller step.

Michael Nielsen, Neural Networks and Deep Learning, chapter 1, “Learning with gradient descent.”

Holds only while the input is positive. A negative input flips the raise/lower choice. That case is not in lesson 0001.
