# Mission: Train a model yourself

## Why
You can already program, and you want to train and fine-tune models rather than only call an API. The change you are after is being able to run a training loop on your own data and know which number you changed when the run goes wrong.

## Success looks like
- Train a tiny model from scratch in code and point to the line that updates the weights.
- Fine-tune an existing model on a dataset you chose, and name the settings you changed.
- When a run fails, change one thing on purpose and say why.

## Constraints
- Lessons stay about ten minutes.
- You program already. The math is rusty, and machine learning is new, so each lesson carries only the math that step needs.
- One idea per lesson.

## Out of scope
- Serving models, deployment, and production infrastructure.
- Reading the frontier-model literature before you can train a small model.
- A standalone linear-algebra course. Algebra appears only inside a training step that needs it.
