Lesson 0001 · about ten minutes

One training step

Training a model is repeating one decision: nudge a weight so the prediction gets less wrong.

Tied to the mission in MISSION.md: you want to train a model yourself, so the first skill is the update every training loop performs. Cheat sheet: one training step.

One weight

For this lesson the whole model is one number, the weight. The input is fixed. The prediction is the weight times the input.

prediction = weight × input

Take input 2 and weight 1. The prediction is 2. The target, the number you wanted, is 8.

Loss

Loss is a single number for how wrong the prediction is. Here it is the squared gap:

loss = (prediction − target)²

Zero means the prediction matches the target. Anything else is positive, and bigger means more wrong. (2 − 8)² = 36.

Michael Nielsen calls this a cost, and uses the average squared error over a whole dataset, with a factor of one half. Training code calls the same idea a loss. Dropping the dataset and the one half does not change which way this weight should move. Source: Neural Networks and Deep Learning, chapter 1, the section “Learning with gradient descent.”

The update

Nielsen’s rule is: move each parameter a small step opposite the slope of the loss. On this one-weight model, with a positive input, that rule becomes a direction you can see without calculus.

  • Prediction too low: raise the weight.
  • Prediction too high: lower the weight.
  • Prediction equal to the target: leave the weight. Any move makes a nonzero loss.

The signed rule he writes is v → v − η∇C. η is a small positive learning rate. This page steps the weight by 1 so the direction is obvious. A real step is smaller. The minus sign is the part that matters today.

Drive the loss to zero

The weight starts at 1. Each click steps it by 1. Stop when the loss is zero.

Recall

Answer from the rule, not from the widget you just used. Three questions. A wrong answer leaves the buttons live.

Input is 2. Weight is 1. Target is 8. The prediction is too low. Which update lowers the loss?

The prediction is 2. Raising the weight moves it toward 8.

Input is 4. Weight is 5. Target is 8. The prediction is 20. Which update lowers the loss?

The prediction is 20, above 8. Lowering the weight moves it down.

The loss is already zero. Any other weight makes a positive loss.
